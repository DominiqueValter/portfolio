## 📌 Sobre o Projeto

Este repositório contém o código-fonte do meu portfólio pessoal. A aplicação foi projetada para demonstrar minha atuação em desenvolvimento de ponta a ponta: desde a arquitetura de software, modelagem de dados e APIs no back-end até microinterações, performance e design de interface no front-end.

---

## 🛠️ Tecnologias & Ferramentas

### **Front-End & UI**
- **React.js** — Componentização modular e hooks modernos
- **Motion / React** — Transições fluidas, microinterações e efeitos de rolagem
- **CSS3 / CSS Modules** — Variáveis de tema escuro (*dark theme*), tipografia editorial e responsividade avançada
- **JavaScript (ES6+)**

### **Stack Técnica & Domínio Geral**
- **Back-End & APIs:** C#, .NET 8, ASP.NET Core Web API, Entity Framework Core
- **Bancos de Dados:** PostgreSQL, SQL Server, MySQL
- **DevOps & Deploy:** Docker, Docker Compose, Nginx, Railway
- **Práticas & Metodologias:** Arquitetura em Camadas, Princípios SOLID, Clean Code, Gitflow

---

## 🚀 Estrutura de Seções

1. **Hero / Apresentação:** Introdução objetiva e foco de atuação profissional.
2. **Sobre Mim:** Trajetória, pilares de desenvolvimento (*Full Stack, Interactive, Problem Solving*) e contexto em Curitiba/PR.
3. **Projetos em Destaque:**
   - **Gestão de Frota (Fleet Management System):** Aplicação full-stack em camadas com .NET 8, React, PostgreSQL e containerização completa via Docker.
   - **Atakama Web:** Interface institucional interativa com foco em captação de clientes, usabilidade e animações web fluidas.
4. **Experiência & Impacto:** Atuação no setor público (SEED-PR) em sistemas que processam milhões em orçamento e centenas de milhares de usuários, além de entregas de desenvolvimento web.
5. **Formação Acadêmica:** Bacharelado em Ciência da Computação, Tecnólogo em ADS e distinções acadêmicas.
6. **Contato:** Acesso direto a canais profissionais e disponibilidade para novas oportunidades.
